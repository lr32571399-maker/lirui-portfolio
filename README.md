# 李瑞个人作品集

包含 UI 设计、品牌视觉与 IP 设计项目的个人作品集网站。

正式网站为 https://lirui-design-portfolio.netlify.app/ 。

## 本地预览

安装 Node.js 后，在仓库根目录运行以下命令。

```sh
node tests/preview.cjs
```

在浏览器中打开 http://127.0.0.1:8765/ 。本地预览支持视频范围请求，供人物追视和转场使用。

## 文件结构

- `index.html` 是网站入口，包含首屏与个人履历的页面和交互逻辑。
- `assets/` 包含运行所需的脚本、样式、图片和视频，已包含构建后的组件。
- `components/` 保留标题、作品画廊、IP 卡片和平面设计展区等组件的源码。
- `tests/preview.cjs` 提供本地静态预览服务。

## 网站交互

首页支持人物视线追踪和标题动画。向下滚动进入个人履历，再进入作品目录。点击蓝色文件夹展开 UI 设计、IP 设计和品牌视觉分类。作品详情提供章节导航、图标邻近放大、BOBO 表情墙和海报浏览等交互。

## 部署

将仓库根目录作为静态网站发布目录即可，入口文件为 `index.html`。本地预览程序用于本机浏览。

## 素材与依赖

第三方组件和依赖的许可说明保留在相应目录中。作品图片与视频的使用请联系作者确认。
